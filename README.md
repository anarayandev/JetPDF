# JetPDF

## Overview
**JetPDF** is a lightweight full-stack application that allows users to convert Microsoft Word 9.docx) files into PDF format quickly and securely. With a responsive interface and fast backend processing, it's built for simplicity, privacy and ease of use. Users have no risks of data breach. No data tracking, no unnecessary complexity.

![JetPDF UI](/frontend/public/screenshots/HomePage.png)
![JetPDF UI](/frontend/public/screenshots/DarkMode.png)

## Features
- Upload .docx files and convert them to PDF instantly with a click of a button
- The PDF file gets **downloaded** into the user's system after conversion
- Clean, modern UI built with **React** and **Tailwind CSS**
- Backend powered by **Node.js** and **Express.js framework**
- Handles secure file uploads using **Multer**
- Converts documents using the **docx-pdf library**
- **Dark Mode** toggle enabled

## Live Demo
Visit: *https://jetpdf-frontend.onrender.com/*

## Tech Stack 
- **Frontend**: React, Tailwind CSS, Vite
- **Backend**: Node.js, Express.js, Multer, docx-pdf
- **Deployment**: Render (both backend and frontend)
